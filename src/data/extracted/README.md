# Extracted source pages

Generated by `npm run extract:books`.

- `pages.jsonl`: one record per PDF page.
- `manifest.json`: book and page extraction counts.

Generated output is source text, not approved curriculum content. All records must remain `needs_review` until checked against the original PDF. Empty pages may be scanned/image-only and require OCR or visual inspection. The printed page number is not inferred from the PDF page index.

## Manual visual recoveries

- `manual-recoveries-pass7.jsonl`: structured transcription candidates recovered from the Pass 7 rendered page images.
- Each record preserves `source`, `sourceFilename`, and the 1-based physical `pdfPage`.
- These records are supplemental to `pages.jsonl`; they do not overwrite machine extraction output or automatically enter lesson/question-bank data.
- Every record remains `transcriptionStatus: candidate` and `reviewStatus: needs_review`. No answer keys are inferred; unresolved source ambiguities are explicitly noted.
