# Book Upload Guide

## Accepted files
- Official PDF student books
- Official PDF workbooks
- Official PDF assessment books
- Official PDF teacher guides, when they are part of the supplied curriculum source set

## Naming convention
Use descriptive English filenames where practical, for example:
- `Primary_G1_Connect_Term1_StudentBook.pdf`
- `Preparatory_G2_NewHello_Term1_Workbook.pdf`
- `Secondary_G1_GeneralSecondary_Term1.pdf`

Original filenames are also accepted.

## After upload
The source-processing workflow will extract each page, preserve the source filename and page number, and report scanned or unreadable pages. Academic content will not be published automatically: detected structures must be reviewed first.
