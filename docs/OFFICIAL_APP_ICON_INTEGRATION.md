# Official EngliMensh app icon integration

Approved artwork: user-provided gold 3D E, open book, Big Ben, star, deep blue field, gold frame.

## Source asset
Place the exact original image at `public/assets/englimensh-app-icon-source.png`.
Do not redraw it, add text, substitute another image, or commit a compressed preview instead of the source.

## Generation
After the Android project is generated by the preview workflow, run:

```bash
python3 -m pip install Pillow
python3 scripts/prepare-official-app-icons.py
```

The script generates Android legacy/adaptive launcher resources and 192/512 PWA icons. It deliberately fails if the approved source asset is absent, so a build cannot silently ship a placeholder icon.

## Acceptance
- Android launcher shows the supplied artwork.
- Adaptive icon uses a centered safe-area foreground and deep-blue background.
- PWA icons are generated from the same artwork.
- App label and package ID remain unchanged.
- Verify the built APK resources and attach a launcher screenshot before declaring completion.

This setup commit does not include the binary source artwork; it must be copied from the already supplied user attachment into the source path above before the icon build can pass.
