# استيراد مناهج المرحلة الإعدادية

هذا المجلد مخصص لاستقبال حزمة HTML الأصلية لمنهجي **New Hello** و **Hello Plus** للصفوف الأول والثاني والثالث الإعدادي.

## أماكن الرفع
- `new-hello/` — ملفات منهج New Hello.
- `hello-plus/` — ملفات منهج Hello Plus.

## طريقة الرفع
من GitHub افتح المجلد المطلوب ثم Add file → Upload files، واسحب ملفات HTML والمجلدات التابعة لها كما هي. لا ترفع ملف ZIP فقط إذا كانت المنصة تسمح بفكّه محليًا أولًا؛ المطلوب رفع محتويات الحزمة مع الحفاظ على بنية المجلدات وأسماء الملفات.

لا تعدّل ملفات الكتب الأصلية في `public/books/`. هذه مساحة استيراد منفصلة للمحتوى التفاعلي. بعد الرفع سأفحص بنية HTML والروابط والصور والبيانات، ثم أحدد طريقة ربط المحتوى بالتطبيق دون تغيير المصادر الأصلية.
